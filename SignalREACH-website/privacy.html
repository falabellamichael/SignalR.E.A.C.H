SignalREACH Studio privacy policy

Last updated: October 19, 2026. This policy covers the SignalREACH Studio desktop app (also called REACH Studio), including the version distributed through the Microsoft Store.

Summary

Studio does not include analytics, advertising, or usage tracking, and it does not send your data to the SignalREACH project. It talks to the services you choose to connect, and stores its own data on your computer.

Data stored on your device

Studio keeps its settings, projects, agents, personas, conversation and team-run history, a crash log, and a security audit log in its app data folder on your computer. API keys and account tokens are encrypted with your operating system's secure storage where it is available. You can delete this data at any time by removing the app's data folder or uninstalling the app.

Data sent over the network

  • AI providers you configure. When you chat or run agents, your prompts, the files or code context you include, and tool results are sent to the model provider you selected (for example a cloud API, or a local server such as Ollama, LM Studio, or Lemonade). That provider's own privacy policy applies.
  • Local model status. The usage panel reads model status from local servers you list (by default addresses on your own computer, 127.0.0.1).
  • Built-in browser. Pages you open load directly from those websites. Web searches use DuckDuckGo.
  • Connections and plugins. Services you connect yourself, such as MCP servers or GitHub for plugins, receive the requests needed to use them.
  • Optional Jev context check. If you turn on Jev and add a key, Studio sends short requests (up to 500 characters of your latest message, plus names of code symbols, not their source) to api.typesafe.ai to decide which code context to include.
  • Optional hosted account and subscription. If you sign in to a hosted REACH account or buy a subscription, the account service and the payment page (Stripe or PayPal) receive what they need to sign you in or process payment. Studio does not see or store your card details.

Optional website builder

The homepage’s Try LFM3 VL feature saves a generated website project in this browser’s local storage. It does not accept uploads or read files from your computer. When you send a request, your prompt and your generated project files are sent to the hosted REACH model service using your signed-in REACH account. Your account’s model access and usage limits apply. Prompts and replies stay in page memory; the project files remain in this browser until you start over or clear site data. Previews run in a sandbox separate from your account session, with their own project storage. Generated pages can load HTTPS resources and public APIs selected by their code. Do not include secrets or personal information in a project or prompt.

Children

Studio is a developer tool and is not directed at children.
