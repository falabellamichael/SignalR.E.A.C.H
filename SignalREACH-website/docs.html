START HERERun from source

Your first REACH workspace.

Start with REACH Studio, then connect it to your chosen endpoint. The steps below follow the current Studio guide in the project repository.

Before you start: install Git and Node.js 24 LTS for the Studio application. You will also need an accessible OpenAI-compatible endpoint and any credentials required by its host.

1

Get the project and start Studio.

Run these commands in your terminal. Review the repository and dependencies before installing.

Terminal
git clone https://github.com/falabellamichael/SignalR.E.A.C.H.git
cd SignalR.E.A.C.H/studio
npm ci
npm start
2

Connect your model.

In Studio, open Settings → Connection & default model. Enter your endpoint, access key if needed, and default model. Your host determines which models are available.

3

Open a project.

Choose Open Folder for an existing project, or New Project → General project to start with an empty folder. Then start a conversation with the context you need.
