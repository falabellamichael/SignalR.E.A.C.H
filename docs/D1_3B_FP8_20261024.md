# D1 3B FP8 user access

The resident support service now loads `LiquidAI/d1-3B` alongside BGE M3,
BGE reranker and Omni600M. 331 aligned linear layers use E4M3FN FP8 weights
and dynamically quantized activations. Embeddings, output head and other
nonlinear layers remain BF16. Model tensors occupy 3,386,588,940 bytes;
GPU 1 reports 7,648,419,840 bytes free after deployment.

The installed account catalog includes `d1-3b` for the same subscription/request
eligibility as other hosted models. Customer sessions and model API keys can
POST `/v1/decisions` using their existing service origin. The relay forwards
customer requests to the account service, preserving authentication rather than
using the owner-key bypass. Existing request reservations, account eligibility,
concurrency limits, settlement and idempotent replay apply. This does not grant
free access to accounts without their normal model entitlement.

```json
{
  "model": "d1-3b",
  "state": "Please refund the duplicate charge.",
  "questions": {
    "refund": {
      "type": "noul",
      "instructions": "Does the customer request a refund?"
    }
  }
}
```

Questions support `noul` (yes/no probability), `choice` (named criteria), and
`score` (ordered criteria). D1 is a native decision operation, not a chat model;
`/v1/chat/completions` is rejected for this route. Catalog capabilities advertise
`chat:false`, `decisions:true`, `/v1/decisions` and FP8 precision. Clients need
native decisions support; no generic chat UI conversion is implemented.

## Verification

- BF16/FP8 comparison: France probability 0.9707/0.9669; refund classification
  unchanged; urgent-problem probability 0.01591/0.01406.
- Live resident refund probe: 0.9890 probability, 31 input tokens, zero generated.
- Account gateway integration test with real GPU fetch passed for eligible
  account, denied account, request settlement, and catalog discovery. It uses
  a test account/ledger; no real customer's credentials or balance were used.
- 28 account/model/API-key tests and 31 relay proxy tests passed.
- Installed public account configuration advertises D1.
