# Interface icons

Unmodified regular-weight SVGs from `@phosphor-icons/core` 2.1.1,
https://github.com/phosphor-icons/core. MIT license included alongside them.

Kept local for the offline, context-isolated Electron renderer. Color is
inherited through a CSS mask; the icon geometry is not recreated in CSS.

`pencil-simple.svg` is the connection tile edit action. `caret-right.svg` also
serves as the expanding/collapsing indicator in the compact connection rows.
