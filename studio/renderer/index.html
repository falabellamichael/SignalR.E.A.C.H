    Conversation context
    Plan
      Team chat

      Follow-ups include your earlier messages and team answers. Turn this off to send only the new message.

      Custom Agents

      Reusable personas: a name, an optional model override, and custom instructions that replace the generic assistant identity.

      Teams

      A crew of custom agents. Parallel: every member gets the same task and they run simultaneously. Chain: members run in order, each one's answer is handed to the next.

      Connections

      Each connection is one endpoint with its own access key and default model. The selected connection is the one every conversation, the playground and the refactor workbench use. Changes apply when you press Save Settings.

      TypeSafe Jev context selection

      Auto uses enabled connection models and saved teams. It keeps your permissions and falls back to your selected setup when uncertain. The Auto switch in each conversation overrides this default. Explicit @ routes, slash commands and a manually selected team take priority.

      Sends a short user request and candidate symbol names and paths to TypeSafe to check whether code context is useful. Retrieved source and tool output are excluded from the Jev request. Uncertain or failed decisions keep the usual context. Jev calls use API tokens.

      Budgeting

      Control how long agents can work, how much they can generate, and how teams share context. Saved changes apply to new runs.

      Zero means no REACH Studio cap where indicated. For output tokens, zero lets the provider choose its default; it does not guarantee maximum output.
