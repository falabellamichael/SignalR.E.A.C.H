## Description for review

REACH Credits (RCH) is an Ethereum ERC-20 token used by the REACH Studio
project. The project's hosted redemption service quotes US-dollar-denominated
prepaid AI usage credit for an exact RCH amount using a market quotation.
Successful treasury redemption transfers RCH to the project's treasury; it
does not burn the tokens. The hosted service credits the linked account after
verifying Ethereum transaction finality. Redemption is currently an owner-wallet
pilot with service limits, not unrestricted public redemption or a fixed-dollar
guarantee. RCH trades in an Ethereum Uniswap v3 RCH/USDC pool.

## Submission steps and missing account details

1. Sign in at https://partner.coingecko.com/request-form/new.
2. Choose New Coin/Token Listing and Active Listing, unless an existing listing
   for this exact contract is now available.
3. Enter the verified details and attach the original orange `rch-logo.png`.
4. Supply the project representative's actual contact and any mandatory
   verification, website, or social details. Do not invent missing fields.
5. Use Regular Pass unless expedited paid review is explicitly requested.
6. Complete any CAPTCHA personally, review the terms and submission, then
   record the resulting request ID and status. Approval is controlled by CoinGecko.

Do not submit multiple requests for the same change. Neither a submission nor
source verification clears MetaMask or Blockaid security classifications.
