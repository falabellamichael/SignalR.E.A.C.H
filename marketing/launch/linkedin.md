I've just opened up REACH Studio, an open-source desktop workspace for AI agent teams.

The idea: your project, your agents, and a browser in one window, using the AI provider you already pay for (or none at all).

• Agent teams with custom personas, parallel reviews, and sequential handoffs
• A built-in browser agents can use, behind your approval settings
• Budgets and live telemetry so agent runs stay bounded
• File edits you review before they're written
• A VS Code extension for in-editor work

It's bring-your-own-key: OpenAI, Gemini, DeepSeek, or local models through Ollama, LM Studio, or Lemonade. Data goes to the provider you choose.

MIT-licensed on GitHub, Windows build on the Microsoft Store. I'd value feedback from teams evaluating agent workflows.
