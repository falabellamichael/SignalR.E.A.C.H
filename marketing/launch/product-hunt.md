# Product Hunt draft (submit manually)

**Name:** REACH Studio by SignalREACH

**Tagline (≤60):** Desktop agent teams with your own keys or local models

**Description (≤260):** REACH Studio is an open-source desktop workspace for AI agent teams: custom personas, a built-in browser agents can use, budgets, and reviewed file edits. Bring your own OpenAI, Gemini, or DeepSeek key, or run locally with Ollama, LM Studio, or Lemonade.

**Topics:** Developer Tools, Artificial Intelligence, Open Source, Productivity

## Maker first comment

Hey Product Hunt! 👋 I made REACH Studio because I wanted my agents, my project files, and a browser in one window, without being locked to one provider.

What you get:
- **Agent teams** – personas with editable SOUL.md / MEMORY.md, parallel reviews or sequential handoffs, per-member Stop/Start.
- **Built-in browser** – agents can browse, search, read, click, and type, behind your approval setting.
- **Budgets & telemetry** – keep agent runs bounded; see loaded local models from Ollama, LM Studio, or Lemonade.
- **Files & editing** – project-bound conversations, branching, review edits before they're written.
- **VS Code extension** for when you'd rather stay in the editor.

It's **bring-your-own-key**: your OpenAI, Gemini, or DeepSeek key, or fully local models. I don't resell model access.

The code is MIT. If it's useful to you, GitHub Sponsors and the optional Subscription Plus are how it stays funded. I'd love to hear what you'd build with an agent team.
