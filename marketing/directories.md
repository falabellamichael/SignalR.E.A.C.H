## Reusable blurbs

**Short (≤60):** Desktop AI agent teams with your own keys or local models

**160 chars:** Open-source desktop workspace for AI agent teams: personas, built-in browser, budgets, reviewed edits. BYOK OpenAI/Gemini/DeepSeek or local Ollama.

**Long:**
REACH Studio is an open-source (MIT) desktop app for Windows, macOS, and Linux that brings AI agent teams, a built-in browser, and your project files into one workspace. Create personas with editable SOUL.md and MEMORY.md files, then dispatch teams for parallel reviews or sequential handoffs, with Stop/Start per member. Agents can browse, search, read, click, and type in a sandboxed browser under your approval settings. Budgets, a live activity view, and a telemetry dashboard keep runs bounded and visible; file edits can be reviewed before they're written. A companion VS Code extension brings chat and agent tools into your editor. SignalREACH is bring-your-own-key: connect your own OpenAI, Gemini, or DeepSeek key, or local models via Ollama, LM Studio, or Lemonade, through any OpenAI-compatible endpoint. No model access is resold.
