6. [ ] Make sure the latest Microsoft Store and GitHub release builds are live; test download links.

9. [ ] Same week: Product Hunt (schedule launch 12:01 AM PT), reply to every comment.
10. [ ] Reddit: r/LocalLLaMA and r/selfhosted on separate days; read each sub's rules first.
11. [ ] X thread + LinkedIn post, linking the demo video.
12. [ ] Directory submissions (`directories.md`), ~5 per day; track status in a sheet.
13. [ ] Outreach: 5–10 personalized emails/week (`outreach/email-templates.md`); log opt-outs.
14. [ ] Weekly: answer leads helpfully, collect feedback into GitHub issues, update CHANGELOG.
